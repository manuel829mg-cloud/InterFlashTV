# Inter Flash TV — reproductor local 0.15

Aplicación Android TV con interfaz y reproducción nativas. Se vincula con el panel Inter Flash y sincroniza la lista M3U configurada allí.

La compilación de esta rama es una app separada para conservar instalada la versión anterior durante la prueba. Requiere una suscripción y enlaces de canales que el usuario esté autorizado a reproducir.
